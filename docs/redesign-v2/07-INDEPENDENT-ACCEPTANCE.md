# DaoFlow V2 独立验收与返工协议

验收者必须是新的未参与实现上下文。开场假设：Current implementation may be incorrect。只收01需求、03规格、05计划、06追踪、候选commit、运行说明和证据路径，不接收“已通过”的期望结论。不改产品代码，不为通过验收降低标准。

## 候选冻结
总控将产品代码提交成独立commit，暂停写入，记录git status --porcelain与git rev-parse HEAD。没有干净候选不得正式验收。验收者可写`docs/redesign-v2/reviews/`和`docs/redesign-v2/evidence/`，身份与文件路径记录到报告；敏感测试数据用虚构内容，截图不出现真实邮箱/日记/密钥。

## 逐条复核
1. 独立读取PRD/SPEC，按R01–R11和U01–U11在浏览器操作，不只看开发者截图。
2. 首屏1440×900和390×844：标题/模式切换/输入/主按钮可见；导航三项；六境在编辑器后、经典在六境后；AI画面真实加载。
3. 录屏：首屏→选“焦虑与情绪”→选建议→编辑→问道→回应→原文；另外记录保存→归卷→刷新→编辑→回收→恢复。
4. 两用户独立认证并通过用户token测试所有新表/RPC/API：A读取/更新/删除/归入B对象均不能成功；导出不含B；请求不能覆盖user_id和AI结果。
5. 执行自动检查：现有与新单元、API、数据库集成、浏览器E2E、生产构建。至少一条真实认证数据库闭环；mock只标mock。
6. 模拟重复请求同UUID、不同payload、冲突version；断网、服务不可用、登录失效、模型降级、结果暂存/入库失败；不得丢草稿或显示假成功。
7. 新旧迁移兼容；旧收藏导入；超过20条记录翻页；同时间戳稳定顺序；永久删除只影响规定数据；导出解析核对数量和内容。
8. 全键盘、焦点、减少动效、前进后退、连续点击、手机翻页、字体完整性与长文可读性。

## 视觉判分（独立主观评分，不声称统计客观）
| 维度 | 分数 | 对照 |
|---|---:|---|
| 层级与任务可见 | 20 | 记录/问道发现容易，回应优先，次级不抢主操作 |
| 古风美术一致性 | 20 | 青绿山水、纸面、题签、印章同画风，无摄影拼贴和默认占位 |
| 中文排版 | 20 | 标题/正文/题签分工、断行自然、字号和对比满足规格 |
| 强交互完成度 | 20 | 六境、墨染、纸页、保存反馈均可实际操作，动作与结果相连 |
| 手机与状态完成度 | 20 | 小屏可操作，加载/空/错/禁用/冲突状态均成型 |

视觉PASS：总分≥85且各维度≥15，无硬失败；每一扣分附截图位置和明确调整建议。总分不能抵消缺核心功能。硬失败：缺AI实际画面、仍旧拱形摄影首屏、假收藏/假保存、私密越权、原文伪造、键盘无法提交、动效卡住界面、只交效果图/静态demo。

## 结果与返工
报告含：reviewerId、freshContext、日期时间、sourceCommit、文档hash、环境、数据、命令、截图/视频、逐R判定、五项视觉分、缺陷、结论PASS/FAIL/BLOCKED、无代码修改声明。
缺陷格式：ID / 对应R与S / 复现步骤 / 预期 / 实际 / 证据 / 严重度 / 分类 / 修复负责Agent / 复验方法。分类IMPLEMENTATION_BUG回实现；REQUIREMENT_GAP回遗漏文档；ARCHITECTURE_GAP先新恢复规格与独立审查再修。
总控按文件负责人派返工，保留原FAIL文件，使用round-01、round-02等新报告。修完形成新commit，影响证据失效重跑，独立者再验。不能为结束任务改分、删失败场景、用自检顶替独立检查。
真实用户尚未试用时写BUSINESS_UAT_PENDING，不阻止交付已技术验收的本地产品，但不得称PILOT_READY/生产上线。
