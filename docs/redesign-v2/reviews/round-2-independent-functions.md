## 独立浏览器实际操作

以下操作使用两个隔离的 Chromium 会话，经 Mailpit 邮件页面实际点击魔法链接；邮箱、UUID 和正文均为虚构测试数据，未在报告保留。

1. **认证和会话**：A 发送魔法链接 → Mailpit 收到邮件 → 在邮件 iframe 内点击 Sign in → 回到本地回调页显示账户；刷新后账户仍在。B 独立重复该流程；B 退出后回到无账户登录表单。
2. **心笺与回收站**：A 新建心笺、保存、刷新后读取原内容；创建卷册并把心笺归入。心笺移入回收站后输入和问道均禁用；恢复后重新可编辑。永久删除先弹出原生二次确认，明确“只会删除这封已回收的记录”，本轮选择取消后恢复该虚构记录。
3. **版本冲突**：同一账户两个浏览器标签加载同一心笺；标签 A 保存标题，标签 B 保存旧版本。B 得到“远端已有版本 2。本地草稿未被覆盖”的冲突入口、本地输入保留、“加载远端版本”按钮和离开提醒。
4. **卷册**：新建卷册后计数从 0 变 1；卷内显示该心笺时间线。归档后仍可阅读和移出，且没有“在此卷新建心笺”入口；恢复后入口返回。
5. **经典收藏**：目录实际列出第 1–81 章。第 8 章整章收藏、批注保存、刷新后批注仍在；实际鼠标拖选连续原文片段后点击“收藏选中原文”，新增的收藏只含所选连续片段。
6. **搜索和导出**：搜索命中虚构心笺；不存在的检索词显示明确空态；清空后恢复列表。UI 公开“导出我的数据”日期入口和 JSON 下载按钮，实际下载 schemaVersion 1 JSON；其中当前 A 的 entries/volumes/favorites 分别为 1/1/1、askSessions 为 0，且包含 A 的虚构条目和卷册。
7. **真实 Agnes 与恢复**：普通虚构问题从首页进入 AskPage 并实际提交。浏览器网络响应为 `provider=agnes`、`degraded=false`、`persistence=saved`；卷册列表出现问道历史链接，打开 `/ask?sessionId=...` 后刷新仍能读取同一回应和可信章节原文。
8. **记录转问道**：对 509 字的虚构心笺点击“带着这条记录问道”，出现可编辑问题对话框，明确提示“超过500字，请自行提炼”，没有自动发送；此时 URL 只含 entry ID、无正文。回收站状态下该入口不出现。
9. **两账户隔离**：B 在真实登录状态下直接用浏览器访问 A 的心笺 URL，页面只显示“记录不存在或你没有权限访问”，未显示 A 内容；访问 A 已保存问道 URL 同样只显示无权限状态，未显示问题、回应或原文。
10. **故障保留、键盘和响应式**：将 A 浏览器置为 offline 后提交虚构心笺，页面显示“没有保存成功。你的文字仍在这里”，输入未丢失；恢复网络后同一输入可重试并清空。全局“动态效果”可切为关；Tab 焦点可达账户链接。320/390/768/1440/1920 宽度下 `scrollWidth` 未超过可用 `clientWidth`（两者差异仅为纵向滚动条）。

临时 Playwright snapshot、下载和控制台记录位于受忽略的 `.playwright-cli/`，不作为提交产物；本报告只记录上述可复现动作和结果。
