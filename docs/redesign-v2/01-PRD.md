## 决策与优先级
用户本轮明确确认：古风、高级排版、动态水墨、强交互、AI 生成界面资源、记录与问道并列、一事一卷、经典收藏。优先级：本轮用户要求 > 本目录通过审查的规格 > 旧 CLAUDE.md / PROJECT_CONTEXT.md / 旧设计文档 > 现有实现。新方案替代旧文档的禁红色、禁印章、禁插画卡片、冷色极简、巨型旋转太极首屏和所有页面原文优先。保留经典出处真实、AI 不代替用户作决定、凭据服务端保管、已有问道降级与登录能力。

目标用户：希望记录生活、梳理困惑、借经典反思的个人。核心闭环：记一句 → 保存 → 归入一事一卷 → 主动把记录转为问题 → 保存回应并关联原记录 → 再次打开看到完整过程。另有读经典 → 收藏整章/原文片段 → 查看、修改批注、取消收藏。

## 明确产品行为
记录正文纯文本，1–10000字符；标题最多60字符；可选心情仅使用 calm/uneasy/sad/angry/hopeful/mixed，不自动推断。所有记录默认私密，无公开分享。未登录可写未保存内容，但保存须登录；界面提前提示，认证回跳保留当前标签页草稿。退出登录清理该账户本机草稿。默认不长久存储未登录私密草稿；刷新前有未保存提醒。

一个记录/问道最多属于一个卷册；卷册可不限数量内容。收藏与卷册独立，本版不做收藏归卷。记录移回收站后，其关联问道仍可在全部问道看到，显示“来源记录已移除”；永久删除记录仅删除来源关联，不删除独立问道历史。删除卷册采用归档/恢复，不做永久删卷。回收站永久删除需页面明确确认，无自动清理。

问道仍为单次请求，不伪装多轮聊天。只有用户点击问道，才将选定文本送往模型。云端写入成功才称“已保存”；匿名问道不保存为云端历史。记录原文超过500字符时让用户选择或编辑问题，不静默截断。普通用户自己的文本允许编辑，不承诺版本历史恢复。AI 回答保留生成时快照，不能因原记录后来编辑而变更。

## 边界
首版不做：AI 周报/心理评分、未来信提醒、连续打卡、公开社区、多人共享、语音上传、付费体系、向量库、多轮聊天。后续想法不自动变成开发任务。
交付目标：本地完整产品 + 自动检查 + 真实本地认证数据闭环 + 独立视觉/功能验收；正式上线、购买素材/套餐、生产迁移不是本提示词授权范围。真实用户UAT由用户试用后记录，不能由智能体冒充。缺外部凭据时先完成其他工作，明确列出未验收链路。
